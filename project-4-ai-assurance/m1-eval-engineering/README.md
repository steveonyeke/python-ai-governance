# M1: Evaluation engineering and measurement rigor
Status: BUILDING | Release: v0.2 | Days 1 to 11 | Started 23 Nov 2026

## Goal
Learn to build and measure evaluations in Inspect, the UK AI Security Institute's evaluation framework, with the judge treated as a measured instrument and not a trusted one.

Pass threshold:
- 3 tasks run in Inspect
- each sample run 5 times
- judge-versus-human Cohen's kappa reported on 30 blind labels, before and after any rubric revision, with every disagreement classified as rubric gap or judge failure
- 2-judge agreement reported
- every failure tagged agent, environment or grader
- v0.2 tagged
